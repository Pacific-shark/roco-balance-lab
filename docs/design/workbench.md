# 工作台视觉与交互规格

主参考为同目录 workbench-concept.png，1536×1024。概念通过内置Image Gen生成一次，作为实现参考，不作为界面背景切图。无游戏美术、音视频或模型调用装饰。

白色主背景 #fff；浅灰绿侧栏 #f4f7f6；文字 #243a34；主按钮 #176b52；边线 #dce5e2。微软雅黑／苹方回退；主标题32px、模块标题22px、正文15px、辅助13px。圆角4px，桌面225px侧栏；主区24px内边距。桌面队列与表单并排，小于1100px上下排列，手机侧栏改为横向导航。

组件：研究队列、六行分页表格、对象与角色选择、预算表单、任务列表、证据报告对话框。界面文字由代码渲染，不加入营销徽标或虚构胜率。

概念的数据占位不作为事实：实现改用真实图鉴编号与顺序，增加分页以浏览全部候选；“训练API token”只统计训练器调用，开发对话不在此指标内。报告、资料和失败状态沿用同一套排版与色彩。已核准报告数保持0，不能用原型报告凑数。

主流程：搜索／筛选→选对象→设置预算→创建→暂停／继续→查看进度或报告→下载JSON。只有已接入原型的对象可运行；正式研究入口保留说明但禁用，服务端也拒绝。

验证：在隐藏的内置浏览器以1536×1024与390×844检查，未启动可见游戏窗口或媒体。使用view_image对照概念与桌面实图，核对文字层级、双栏结构、字级、白色与绿色配色、间距和表格容器。修复全局样式引入的40px导航上边距；同名形态增加形态说明；对话框使用原生模态焦点约束。原始概念编号占位、空任务状态改为实际编号、分页与真实任务，属于事实和交互补全。主流程可操作，控制台无错误，手机无水平溢出。
