## 读取与校验

1. 从可见精灵列表逐页读取 11 页、625 条形态，展开全部字段；技能列表读取 579 项，特性列表读取 242 个名称。
2. 通过公开 MediaWiki Action API 读取站点数据模块，使用仅支持字面量的 Lua 解析器；不执行第三方 Lua，不复制渲染逻辑。
3. 对照 625 条可见记录的六项种族值、总值、属性与特性说明；比较技能与特性名称集合；验证全部学习来源引用。
4. 规范化为 `public/data/bwiki-2026-10-14.json`，保留内部 ID、原条目链接、学习条件与模块修订号。

## 训练子集的独立来源

`src/data.mjs` 仍保留先前人工整理的 S3 六精灵快照和对应 `rocokingdom.gg` 链接。伤害公式参考社区 [Roco Showdown 计算说明](https://roco-showdown.com/battle-use-guide)，引擎独立实现。

旧子集没有静默替换成当前 BWIKI 数据，避免新旧版本与已有模型混用。它包含统一生命、聚能回复 4、40 回合截断等明确实验假设。当前 BWIKI 与旧资料的属性关系已有差异，不能把旧模型分数贴成 S4 结论。

## 更新方式

`scripts/wiki_data.py` 是字面量解析器。`scripts/import_wiki.py` 以公开接口响应和同日页面核对记录为输入，在验证通过后生成快照。更新数据时必须重新收集对应列表、核对模块版本并复跑检查；不能只修改 JSON 日期。

数据许可证与权利范围见根目录 NOTICE。第三方原始缓存、网页账号信息和渲染代码不放入仓库。

可尝试重新读取，并拒绝与快照修订号不一致的响应：

```sh
python scripts/fetch_wiki_snapshot.py
python scripts/import_wiki.py .cache/wiki-snapshot
```

页面读取证据保留在 `docs/evidence/`，同样采用 CC BY-SA 4.0；不含账号信息或图片。抓取失败时脚本直接报错，不替换为其他版本。

复查时公开接口返回 HTTP 567，在线重新读取尚未再次验证成功；已成功取得的本地缓存可正常导入。仓库已提供规范化快照和页面核对证据，运行演示不依赖该接口。
