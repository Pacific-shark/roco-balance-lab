# 图鉴页面

首页为纯静态图鉴，`research.html` 保留原研究工作台。两者采用独立入口，浏览图鉴不加载训练逻辑，也不请求本地 API。

## 内容与交互

- 名称、编号搜索，属性与形态筛选；覆盖快照内全部 633 条形态，不把形态数写成精灵物种数。
- 原立绘、六维种族值、特性、普通进化链与首领分支；首领形态不混作普通进化阶段。
- 配队按当前精灵关联，数量不限；每套记录独立的六名成员、四招、性格、血脉、天分方向和整队共鸣。
- 电环水队完整配置按来源转录；水沙队与纯血雨天队仅收录已确认名单，其余字段为 `null` 或空数组。未核对的内容不自动推断、也不从其他队伍继承。
- 技能池按基础可学、技能石、血脉与特殊学习分开，显示能耗、威力、描述及学习条件。血脉技能可以继续筛选对应血脉。
- 地址片段保留当前精灵、队伍和队员，刷新可以恢复；手机布局支持横向图鉴列表和两行六人头像。

性格只展示来源记录的名称与增减方向；页面不计算实战面板，不声称性格全局最优。配队案例不提供未经实测的胜率或强度评分。

## 资料更新

原始版本：`data/catalog-s4-20261016-review.json`，读取时间 2026-10-20。资料来自 BWIKI 玩家社区，不代表全部正式服更新已经核验。

```sh
# 可选：查询公开图片地址；三并发、每批 40 个文件名，默认复用已有清单
python scripts/resolve-dex-images.py

# 离线导出静态页面数据；跨版本技能按 game_id 对齐
pnpm dex:export

# 检查资料关系与来源配置
node --test test/dex.test.mjs
pnpm build
pnpm preview
```

图片清单保存 1,206 个不重复的头像／立绘 URL。每条形态均有这两类图片；不同形态可能共用文件。网页懒加载图片，失败时显示名称占位；源站图片删除或访问失败可能影响展示。

新增配队在有来源后添加到结构化案例中，再扩展导出器。完整配置要求六名不同成员、每名四招、可学习来源与对应血脉成立。状态 `roster-recorded` 只表示名单可见，`build-recorded` 表示配置已转录；均不等于已通过实机对战核验。
