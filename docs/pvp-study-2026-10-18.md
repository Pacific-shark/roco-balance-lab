## 从资料中得到的建队认识

### 1. 先找资源链，再决定成员

不是看两只精灵属性相同就判断协同强。需要明确谁创造条件、条件记录在哪里、谁在何时兑现，以及为此占用了多少行动和技能槽。

| 联动方向 | 从特性／技能文本能建立的联系 | 必须验证的代价和断点 |
| --- | --- | --- |
| 水灵→彩蝶鲨 | 水灵的水系行动同时推进自身减费和队伍水系使用历史；彩蝶鲨入场可兑现减费。落雨提供攻击窗口 | 谁负责开雨、什么时候换入、是否携带能兑现收益的攻击；重复入场的计数语义、天气剩余回合；雨天也帮助对手 |
| 火系行动→火焰猿／烈火守护／火巨人 | 同一类前期行动分别转化为入场能量、技能威力、面板成长，兑现方式不同 | 三者不应无条件塞进同队；铺垫期间的损血、换入机会和剩余魔力是否容许兑现 |
| 应对成功→瞌睡王／海豹船长 | 分别为入场前能量、水／武技能威力创造条件 | 应对成功需要对手配合或正确判断；和“使用防御技能”不能混为一个事件 |
| 防御技能→波多西 | 记录防御技能使用，提升入场后的特定系别威力 | 不等于防御应对成功才记数；具体生效范围和切出后保留要核验 |
| 奇丽花→场下队友 | 自身回合末回能支持持续行动；主动技能富养化才是场下回能来源 | 富养化占一个技能槽和一次行动；有效回能与满能量溢出分开统计 |
| 琉璃水母↔裘卡 | 前者根据中毒印记施加中毒，后者把中毒转换为印记；千棘盔可提供启动与其他功能 | 转化、离场、力竭和回合末的顺序；驱散、免疫、对手压制以及轮转成本 |
| 印记生产→星陨兑现 | 怖哭菇等提供印记；基础星陨词条由非幻系攻击触发，暮星辰改变消耗方式 | 不只累计层数，还要安排兑现者、时机、技能系别与印记保护；不能把所有幻系攻击都视为默认触发 |
| 入场收益→轮转工具 | 音速犬首回合收益、酷拉首次行动、爵士鹿入场成长等，可能因反复安全入场获得价值 | 主动换人、脱离、返场和力竭后补位不同；棘刺、降灵与梦悠悠等会惩罚换人 |
| 萌化→卡洛儿／魔眷鸟等 | 不同精灵能将自身或队友的萌化转成资源或连击；不能只把萌化当纯负面 | 哪个成员承担面板变化，能否继续承伤或输出，变化与继承规则是什么 |

这些是**有文本依据的联动假设**，不是已经验证的强队清单。来源为固定快照中对应特性、学习表及 Terms；雨天小轴还有用户实战经验作为线索，毒循环有历史教程讲解作为补充。

雨天轮转教程还提供了一个重要区分：作者的 S3 构筑强调不依赖主动开雨，并在约 02:20–03:30 解释水灵留场同时为彩蝶鲨积累被动。因此水系行动预热和天气增伤需要分别记账；不能把“雨天队”这个名字当作完整的玩法说明。此结论来自作者讲解与特性文本的对应，尚未完成当前版本对局核验。

### 2. 小轴成立，不代表六人队伍已经成立

水灵和彩蝶鲨可以承担一条资源与输出链；另外四个位置仍需回答：谁承接它们不利的对位，谁处理强化和印记，谁保证进场，谁应付对方更快的进攻，主路线被拦截后由谁继续施压。

这些是功能问题，不是强制“一位只做一件事”的六种固定职业。一个成员可以兼任联防、清理印记和次要输出；角色应由具体四招、培养和实际操作确定。也不能把研究目标永远当成主攻手。

历史多核队教程提供的有用思路是：一个主攻点被拦截后，让其他成员继续给压力，并通过补能、联防为它创造再次入场机会。这个思路可以研究，旧教程的技能数值、首领安排和自报胜率不能直接沿用。

### 3. 看起来相似的机制必须分开

- **特性与主动支援分开。** 奇丽花被动回能归自己，场下队友补能来自富养化。记录支援时不能把两者重复记账。
- **虫鸣与奉献分开。** 虫鸣关注全队携带同名技能的数量；当前来源词条中，奉献强化的是啃咬和虫群。不能推导成所有虫系技能都一起变强。
- **使用防御与成功应对分开。** 波多西、瞌睡王、海豹船长的触发要求不同，不能共享一个模糊的“防御次数”特征。
- **属性、技能属性与血脉分开。** 打击面、条件增伤和血脉技能合法性分别校验；不能为了补盲同时带上不同血脉限定的技能。
- **全局效果要同时计算两方。** 粉耳星兔的回合末增触发、落陨星兔的回合末阻断、雨天、友爱星飞的全队回能，都可能帮助对手或破坏己方计划。
- **减费不一定永远有利。** 利灯鱼会反转能耗变化；斑枭的免伤条件与低能耗攻击相关。持续减费路线需要核对这些对位，不能把每减一点能耗直接记为固定正收益。

### 4. 强化和培养服务具体任务

历史毒队教程明确区分同一精灵作为耐久位、半输出位或收割位时的培养需求。可保留的原则是：用目标对位的速度线、存活线与击杀线比较培养方案。视频中的历史速度阈值、物攻种族和强度描述没有完成当前版本复核，不登记成通用答案。

后续仍按用户要求固定 60 级、五星基准，并搜索合法性格、天分、技能和血脉。所谓“最优”必须带着队伍与对手条件，不能由三个通用培养预设替代。

## 准备怎样把认识变成可训练的基准

每套基准都需要保留以下信息：

| 信息 | 具体记录 |
| --- | --- |
| 来源与版本 | 作者、链接、发布和对局版本、已读时间段、与当前资料的差异 |
| 完整合法构筑 | 六人形态、四招及槽位、血脉、性格、天分、整队共鸣选项；缺项就标待补 |
| 成员分工 | 谁提供条件、谁兑现、谁联防、谁负责清理和另一条进攻路线 |
| 关键决策 | 当时可见信息、可选行动、实际选择、选择理由和被反制后的处理 |
| 资源账本 | 有效能量与溢出、血量交换、天气时间、技能槽、换人损失和魔力代价 |
| 失败样本 | 被什么针对、何时来不及启动、何时应放弃原路线；不能只收胜局 |
| 证据状态 | 文本推断／作者讲解／画面可见／逐事件核对，各自分列 |

第一批覆盖雨天、毒／水毒、火系预热、应对／轮转、多核平衡、星陨、虫系资源等不同方向。这是阅读与补证据的队列，完整测试队仍待核准，也不宣称代表完整环境。

再训练的顺序：

1. 把基准实际使用的技能、特性和交互逐事件对照清楚；不存在“未实现则从候选里静默删除”。
2. 固定真实构筑，检查策略能否学会启动、换人、资源兑现和反制。先证明会操作，再比较配队。
3. 以核实过的构筑为一部分起点，允许替换、改招和改变培养；同时保留全量合法候选的探索通道。人工起点不能包装成 AI 自主发现。
4. 验证对手涵盖其他体系、专门反制和历史策略。雨天等已用于开发的案例不能再冒充未知测试。
5. 只在不同对手、队伍背景和合理适应预算下讨论个体价值。不能给“带上指定搭档”直接加奖励，不能预设水灵和彩蝶鲨必须排名第一。
