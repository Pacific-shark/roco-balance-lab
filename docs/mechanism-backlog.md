# 机制实现清单

完整图鉴已结构化，完整战斗模拟尚未实现。文字描述只用于核对，不能直接当成可执行规则。

| 机制组 | 已读到的例子 | 当前引擎 | 接入前必须核准 |
|---|---|---|---|
| 基础攻击与资源 | 抓挠、火苗、水炮、藤绞 | 部分实现 | 基础生命/伤害、能量下限、减耗叠加和取整 |
| 培养与面板 | 种族值、六项资质、30 性格 | 已实现；一项 +10%/另一项 −10%，600 候选培养搜索 | 面板内外取整、低资质控速、与配招联合搜索 |
| 应对与防御 | 闪燃、防御、硬门、壁垒 | 6v6 样本部分实现，硬门未接入 | 用游戏录像核对优先级、冷却时点与打断 |
| 入退场与队伍 | 地脉、蒸汽膨胀、盘根木、富养化 | 首发、切换、补位、魔力及样本后台机制已实现 | 实战结算、迅捷等例外、愿力和首领化 |
| 状态与印记 | 中毒、灼烧、冻结、萌化、星陨 | 未实现 | 多层计算、系别免疫、换人保留、印记替换 |
| 天气与外部环境 | 雨天、沙暴、雷鸣、安眠、张弛有度 | 未实现 | 战斗允许的环境、昼夜/日期固定方式 |
| 技能槽位 | 传动、正位宝剑、钢钻、盲拧 | 未实现 | 槽位环绕、相邻位置、传动叠加与锁位 |
| 改招与选择 | 复写、巧变、隐藏条款、选择技能 | 未实现 | 候选池、概率、可观察信息、两个分支的记忆 |
| 特殊例外 | 多人宿舍、吟游之弦、陨落、不朽 | 未实现 | 能量越界、事件取消、复活与状态恢复 |
| 合法配招 | 自学、技能石、血脉、传说 | 6v6 样本验证自学/技能石四招 | 血脉互斥及特殊学习条件 |
| 智能体 | 两个独立策略梯度模型、6v6 行动、历史策略池 | 已实现；公开启发式初始化 | 配队配招搜索、隐藏信息推断、独立配置评估 |

每条机制的接入要求：来源版本、触发事件、前置条件、目标、数值与叠加方式、解除时点、结算次序、可复现的游戏内例子和回归测试。缺少其中关键信息时，状态为“待核准”，不能默认无效果或编一个值补齐。

优先级：先用游戏记录校准当前样本结算，再扩展合法配招、状态印记、天气和槽位系统。模型规模与训练局数放在这些条件之后。
