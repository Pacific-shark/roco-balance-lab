# 机制实现清单

完整图鉴已结构化，完整战斗模拟尚未实现。文字描述只用于核对，不能直接当成可执行规则。

2026-10-15官方资料复核见[战斗机制底稿](official-battle-rules.md)。同速同时离场须随机，旧引擎固定同速优先方不符；光合治愈的任意血脉范围及S4基础效果已有原文，额度与边界仍待核验。该底稿和结构化证据中的验收场景均未被计作实机测试通过。

|---|---|---|---|

血脉与共鸣的本轮修订见 [bloodline-mechanisms.md](bloodline-mechanisms.md)：已有来源过滤，以及整队共鸣单选、三者互斥和有限次数记录；具体额度未核准，资源模块未接入对战。愿力／首领化／草魔法的完整结算仍待完成；动态生成愿力与使用愿力强化分别登记。

每条机制的接入要求：来源版本、触发事件、前置条件、目标、数值与叠加方式、解除时点、结算次序、可复现的游戏内例子和回归测试。缺少其中关键信息时，状态为“待核准”，不能默认无效果或编一个值补齐。

优先级：先用游戏记录校准当前样本结算，再扩展合法配招、状态印记、天气和槽位系统。模型规模与训练局数放在这些条件之后。
